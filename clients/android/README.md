# Клиент первичного токен-API СИМПАС

Вход в мобильных приложениях экосистемы. Рецепт подключения —
`docs/integration/practice-android.md`.

**Чистый Kotlin/JVM, без зависимостей от Android.** Так он проверяется обычными
тестами на JVM, а не эмулятором — то есть проверяется вообще. Приложению
подключается как есть: OkHttp и kotlinx-serialization у ПРАКТИКИ уже стоят.

```
gradle test          # 15 проверок против настоящего HTTP (MockWebServer)
```

Обёртки `gradlew` в репозитории нет намеренно: она тянет двоичный
`gradle-wrapper.jar`, который никто не читает. Версия закреплена в
`.github/workflows/build.yml`.

## Границы, заданные требованием

Ни формы входа провайдера, ни webview, ни ухода в браузер — вход идёт первичным
токен-API (`docs/spec/12_NATIVE_AUTH.md`). Учётные данные провайдера сюда не
попадают ни в каком виде.

**Хранение токенов не входит намеренно.** На Android их место в
`EncryptedSharedPreferences` поверх Keystore, и это решение приложения.

**Перехватчики переданного OkHttpClient снимаются.** Таймауты, пул, закрепление
сертификата наследуются; перехватчики нет — иначе общий клиент приложения
отправил бы сюда ключ доступа другой службы, а отладочный журнал напечатал бы код
из письма.
