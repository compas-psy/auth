# SimpasID

Сервис единой идентичности экосистемы СИМПАС: ПРАКТИКА, ЗАПИСКИ, МОМЕНТЫ.
Отвечает на вопрос «кто вы», выдаёт токены по OIDC и даёт публичное API аккаунта.
Больше не отвечает ни за что.

Домен: `auth.cmpas.ru` · `issuer`: `https://auth.cmpas.ru`

**Читать до первой строки кода:** [`CLAUDE.md`](CLAUDE.md), затем
[`design/ЧИТАТЬ_ПЕРВЫМ.md`](design/ЧИТАТЬ_ПЕРВЫМ.md), затем `docs/spec/02_SIMPASID.md` §1.4.

## Что где лежит

```
server/                сервис: Fastify, oidc-provider, pg без ORM
  src/oidc/            конфигурация issuer, адаптер хранения, экраны взаимодействия
  src/api/v1/          публичное API — им же работают портал и продукты
  src/services/        учётные записи, вход по почте и коду, согласия, токены
  src/db/migrations/   *.sql, применяются по порядку при старте
  src/ui/wording.ts    реестр формулировок — ОДИН на сервер и на портал
  openapi/             единственный источник истины
portal/                экраны входа и портал аккаунта (React)
devsite/               ресурс разработчика; справочник ГЕНЕРИРУЕТСЯ из спецификации
packages/id-client/    SDK для продуктов
docs/integration/      рецепты переезда — исполняемые, а не пересказ
docs/reports/E2/       отчёты по задачам: расхождения, ответы context7, непроверенное
deploy/                конфигурация прокси и порядок публикации
```

## Разработка

Нужен Postgres. Строка подключения — в `DATABASE_URL`.

```bash
npm ci --prefix server && npm ci --prefix portal
npm ci --prefix devsite && npm ci --prefix packages/id-client

npm run build --prefix portal     # серверные тесты проверяют собранный портал
npm test --prefix server
npm test --prefix portal
npm test --prefix devsite
npm test --prefix packages/id-client

npm run api:lint --prefix server  # стайл-гайд спецификации
```

Миграции применяются сами при старте; вручную — `npm run migrate --prefix server`.

## Правила, нарушение которых — брак

* **И-1.** Ключевой материал ЗАПИСОК не хранится, не принимается и не передаётся.
* **И-2.** Запрещённых имён колонок нет ни в одной схеме. Проверяется
  `server/test/schema.invariants.test.ts` — он обязан быть зелёным всегда.
* **И-5.** У каждой учётной записи всегда есть подтверждённая почта. Отказ отвязать последний
  способ входа приходит **от сервера**, а не прячется в интерфейсе.
* **Р-2.** Cookie не поднимается на общий домен: атрибут `Domain` не задаётся никогда.
* Портал и продукты работают **одним и тем же** публичным API. Чего нет в
  `server/openapi/simpasid.v1.yaml` — того не может быть и на экране.
* В журналы не пишутся почта, `sub`, токены и пути. Только `ip_hash` и `ua_hash`.
* Тексты экранов берутся из `design/` дословно.
